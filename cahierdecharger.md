1. Présentation du projet
1.1 Contexte
De nombreux clients rencontrent des difficultés pour trouver rapidement un artisan fiable, disponible et compétent pour réaliser des travaux ou des prestations de services.
De leur côté, les artisans ont souvent des difficultés à trouver de nouveaux clients et à valoriser leurs compétences.
Le présent projet consiste à développer une application permettant de mettre directement en relation des clients à la recherche d’une prestation et des artisans capables de la réaliser.
L’application devra permettre au client de rechercher un artisan, de publier une demande, de recevoir des propositions ou devis, d’échanger avec les professionnels et de suivre la réalisation de la prestation.
1.2 Objectif général
L’objectif est de créer une plateforme numérique simple, sécurisée et accessible permettant :
•	aux clients de trouver facilement des artisans ;
•	aux artisans de trouver de nouveaux clients ;
•	aux clients de demander une ou plusieurs prestations ;
•	aux artisans de proposer leurs services et leurs tarifs ;
•	de faciliter la communication entre les deux parties ;
•	de permettre le suivi des prestations ;
•	de créer un système de notation et d’avis ;
•	la création d’un bouton WhatsApp animé +226 63 25 02 02 pour l’administrateur ;
•	de pouvoir installer l’application sur téléphone, ordinateur et tablette grâce au fonctionnement PWA.

3. Utilisateurs de la plateforme
La plateforme comportera trois catégories principales d’utilisateurs.
3.1 Client
Le client est une personne ou une entreprise qui recherche un artisan pour effectuer une prestation.
Il pourra :
•	Créer un compte ;
•	Modifier son profil ;
•	Rechercher des artisans ;
•	Consulter les profils ;
•	Publier des demandes ;
•	Recevoir des devis ;
•	Discuter avec les artisans ;
•	Sélectionner un artisan ;
•	Suivre ses prestations ;
•	Confirmer la réalisation ;
•	Effectuer un paiement si le paiement en ligne est activé ;
•	Donner une note et un avis.
3.2 Artisan
L’artisan est un professionnel proposant des services.
Il pourra :
•	Créer un compte professionnel ;
•	Renseigner ses compétences ;
•	Sélectionner ses catégories de services ;
•	Définir sa zone d’intervention ;
•	Présenter ses réalisations ;
•	Recevoir des demandes ;
•	Envoyer des devis ;
•	Discuter avec les clients ;
•	Accepter une prestation ;
•	Gérer son calendrier ;
•	Consulter son historique ;
•	Consulter ses revenus ;
•	Recevoir des évaluations ;
•	Recevoir des demandes de rendez-vous.
3.3 Administrateur
L’administrateur aura accès à une interface de gestion permettant de :
•	Gérer les utilisateurs ;
•	Gérer les artisans ;
•	Valider ou suspendre des comptes ;
•	Gérer les catégories ;
•	Consulter les prestations ;
•	Gérer les réclamations ;
•	Gérer les avis ;
•	Gérer les paiements ;
•	Consulter les statistiques ;
•	Envoyer des notifications ;
•	Bloquer les utilisateurs frauduleux.

9. Publication d’une demande de prestation
Le client pourra créer une demande.
Il devra renseigner :
•	titre de la demande ;
•	catégorie ;
•	description du besoin ;
•	photos ;

•	localisation ;

•	budget indicatif ;
•	durée estimée ;
•	niveau d’urgence.
Exemple
Titre : Réparation d’une fuite d’eau

« J’ai une fuite au niveau de la cuisine. Je recherche un plombier disponible rapidement. »
Le client pourra ensuite publier la demande.

Le client pourra choisir :
•	un artisan différent pour chaque prestation ;
•	ou un artisan/une entreprise capable de réaliser plusieurs prestations.

25. Architecture technique proposée
Le développement de l’application reposera principalement sur deux technologies :
25.1 Next.js
Next.js sera utilisé pour développer l’application web.
Il permettra notamment de gérer :
•	l’interface utilisateur ;
•	les pages publiques ;
•	les espaces Client ;
•	les espaces Artisan ;
•	l’espace Administrateur ;
•	les formulaires ;
•	la logique applicative ;
•	les échanges avec Supabase ;
•	les fonctionnalités côté serveur nécessaires ;
•	le référencement des pages publiques ;
•	le fonctionnement responsive sur téléphone, tablette et ordinateur.
L’application sera conçue sous forme de Progressive Web App (PWA) afin de pouvoir être installée sur les appareils compatibles directement depuis le navigateur.
25.2 Supabase
Supabase sera utilisé pour les services backend et la gestion des données de l’application.
Il permettra notamment de gérer :
•	la base de données PostgreSQL ;
•	l’authentification ;
•	les utilisateurs ;
•	les sessions ;
•	les autorisations d’accès aux données ;
•	le stockage des photos ;
•	le stockage des documents ;
•	le stockage des réalisations des artisans ;
•	les données de messagerie ;
•	les données en temps réel lorsque nécessaire.
25.3 Technologies principales retenues
Le projet utilisera donc principalement :
•	Next.js : développement de l’application web et PWA ;
•	Supabase : base de données, authentification, stockage et services backend.
25.4 Services complémentaires
Le projet pourra intégrer, selon les fonctionnalités activées :
•	service de cartographie ;
•	service de notifications ;
•	service SMS ;
•	service email ;
•	service de paiement.
Ces services seront intégrés depuis l’application Next.js et pourront communiquer avec les données stockées dans Supabase.

35. Conclusion
Le projet a pour ambition de créer une plateforme de confiance permettant aux clients de trouver rapidement des professionnels et aux artisans d’accéder à de nouvelles opportunités commerciales.
La première version devra privilégier la simplicité, la rapidité et la mise en relation, avant d’intégrer progressivement des fonctionnalités plus complexes telles que le paiement, la géolocalisation avancée, les abonnements et la garantie des prestations.
Le développement devra être réalisé de manière modulaire afin de permettre l’évolution de la plateforme sans devoir reconstruire entièrement l’application.
